Maprisma Theme interface languages

Language setting: Settings -> General -> Language.
Choices: System (<detected language name>), English, Deutsch, Français, Español,
Italiano, Português, Nederlands, Polski. Saved as language=auto or a language
code in $XDG_CONFIG_HOME/maprisma-theme/settings.json (normally
~/.config/maprisma-theme/settings.json). The Flutter interface changes immediately;
the running tray/applet also refreshes automatically, without restarting.

System fallback: first nonempty LC_ALL, LC_MESSAGES, LANG; locale variants are
reduced to their language code; unknown locales, C and POSIX use English.

English keys. Also localized Name and Comment in all three desktop entries
(6 desktop fields). Counts exclude test-only call sites.
