3. **[P2] Preview cannot restore an image wallpaper with no explicit `Image` entry** — [desktop_kde.dart:166](/mnt/Data/Projects/maprisma-theme/packages/maprisma_theme_core/lib/src/desktop_kde.dart:166). A desktop using the image plugin’s default wallpaper can have `wallpaperplugin=org.kde.image` without a saved `Image`. Its snapshot contains a null image. Preview writes C; restoration skips the image write, leaving C displayed while reporting success. Capture the effective original image or restore the absence of the override.

4. **[P2] Konsole loses settings from a system-provided default profile** — [desktop_kde.dart:213](/mnt/Data/Projects/maprisma-theme/packages/maprisma_theme_core/lib/src/desktop_kde.dart:213). With `DefaultProfile=Work.profile` resolved from `/usr/share/konsole/Work.profile`, `own` becomes null because only the user data directory is checked. Applying a theme switches the default to a new profile inheriting `FALLBACK/`, dropping Work’s command, font, scrolling, and other settings. Resolve profiles across data locations and preserve their settings or inheritance. [Konsole itself uses `QStandardPaths` for this lookup](https://github.com/KDE/konsole/blob/master/src/profile/ProfileManager.cpp).
